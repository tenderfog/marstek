# MARSTEK app icon source

The white MARSTEK mark belongs to MARSTEK. It was obtained from the
[manufacturer’s official website](https://marstekenergy.com/) on 27 October 2026:

- [Original 1000 × 1000 artwork](https://marstekenergy.com/cdn/shop/files/APP_Logo_white.jpg?v=1792570266)
- [Website favicon reference](https://marstekenergy.com/cdn/shop/files/APP_Logo_white_32x32.jpg?v=1792570266)

`marstek-official-app-logo.jpg` is the original downloaded artwork. The logo
was not redrawn or generated. `VenusBar-1024.png` and `VenusBar.icns` only add
transparent macOS icon margins, rounded outer corners and a subtle shadow.
The ICNS includes 16, 32, 64, 128, 256, 512 and 1024 pixel representations.

VenusBar is a third-party application; this use of the manufacturer’s mark
does not claim authorship of the logo or an official MARSTEK application.

The committed ICNS is copied directly into the app. Regeneration is optional:
run `python3 Assets/AppIcon/generate_icon.py` with Pillow installed. The build
does not run this asset generator; the app has no Python runtime dependency.
